# TFM_MLOPS_25_26
Este repositorio contiene una arquitectura MLops enfocada a el reentrenamiento mensual de un modelo XGBOOST enfocado en la predicción de leads, contiene herramientas como Kafka, DBT, AirFlow,MLFlow,Postgres, DataLake + Spark. Todo esto se ha creado en un entorno local mediante Docker-Compose.
